# Instant Pot Recipes

Interactive Instant Pot recipes that scale with the weight of meat you have:
Chicken Tikka Masala and Quesabirria, plus a shopping list.

Live at https://iramillington.github.io/instant_pot_recipes/ (GitHub Pages, `main` branch).
`birria.html` carries schema.org Recipe markup for importing into recipe apps.

No build step: edit the HTML/CSS and push to `main`. See `AGENTS.md` for details.
